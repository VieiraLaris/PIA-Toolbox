# PIA Toolbox

Este repositório foi criado para a documentação do Trabalho de Conclusão de Curso (TCC) do curso de Engenharia de Software da Universidade de Brasília (UnB), orientado pelo docente Bruno Luiz Pereira.

## Objetivo

O objetivo deste projeto é desenvolver uma toolbox para o ambiente MATLAB que permita a criação, configuração e execução de sistemas fuzzy utilizando o método PIA.

A toolbox busca oferecer uma interface inspirada nas ferramentas de lógica fuzzy já disponíveis no MATLAB, permitindo que o usuário trabalhe com os componentes de um sistema PIA de maneira estruturada e intuitiva.
